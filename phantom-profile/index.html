01 / ALIAS

为什么叫「洛基」

代号来自漫威剧集《洛基》。我喜欢他在诡计与宿命之间还保留着幽默和乐观，也记得他最后为守住世界作出的选择。

02 / BOOKSHELF

书架上的浪与水

我喜欢西方哲学和史铁生的散文。印象最深的是《病隙碎笔》结尾的浪与水，以及书里对思想如何在人与人之间传递的思考。

《失乐园》 · 《查拉图斯特拉如是说》 · 《浮士德》 · 《存在主义咖啡馆》

为什么这段文字让我共鸣

我的左耳有重度听力障碍，几乎听不到声音。读史铁生时，我能体会到文字里的绝望与不甘。他的作品促使我反思自己、认真承担责任。我也相信意志能帮助我面对困难。

03 / AFTER CLASS

下课之后

平时喜欢阅读、打游戏、听音乐，也喜欢睡觉和吃东西。最近尤其喜欢 Persona 系列，做这个主页时也想把喜欢的怪盗视觉带进来。

一箱可乐的冰箱事故

刚上大学约一个月，我把一箱可乐放进了急冻层。同学下午开冰箱时，几乎整箱可乐都溢出来冻成了沙冰。我找物业借了根棍子一点点铲，最后手上全是可乐味。

WEB PROJECT / 2026

Phantom Search

一个受《女神异闻录 5》启发的搜索入口。除了多引擎搜索，它把创作者信息藏进一张可翻转的卡片，还用不同的转场串起搜索、档案和反馈页面。

我提出想法和需求，和 AI 一步步搭起框架。AI 协助编写、运行代码。现在的搜索功能比较基础，我想做更多实用项目，下一项还在想。

  • 多引擎搜索
  • 动态卡片
  • 响应式网页
